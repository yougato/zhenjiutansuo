使用指南

穴位名称显示

  • 人体图与圆环图上所有穴位名称实时显示，「图层显示 → 穴位名称」三档：全部（默认）／要穴／关闭
  • 标签为屏幕空间恒定字号，任意缩放均清晰；自动防重叠排布，优先交会/特定穴，放大后显示更全
  • 悬停/选中穴位及聚焦经脉的名称必定显示

🤖 AI 针灸助手（右上角开启）

  • 按症状推荐处方：「我偏头痛」「最近失眠」「胃痛怎么缓解」→ 主穴 + 加减配伍 + 调护建议
  • 穴位问答：「足三里有什么用」→ 穴性 / 主治 / 国标定位 / 配伍
  • 经脉与时辰：「胃经」「现在什么时辰当令」；虚实补泻：「肾虚补什么穴」
  • 推荐结果可一键载入画布组方连线；未配置 Key 时全部本地运行，仅供参考
  • 在线大模型：点助手右上角 ⚙ 可接入 智谱清言（glm-4-flash） 或 DeepSeek，填入自有 API Key 后即可自由问答；调用失败会自动回退本地知识库，回答中的穴位名可直接点击定位

画布操作

  • 拖拽平移、滚轮 / 双指缩放；顶部切换 人体图 / 圆环图 / 全景
  • 点击穴位 → 详情卡（穴性 · 国标定位 · 子母补泻 · 配伍）；双击空白回全景
  • 左上 ◀ 或左缘竖向把手可折叠左侧面板（快捷键 [ / Ctrl+B），折叠状态自动记忆
